# Bingo Pop

A responsive 75-ball Bingo machine built with React, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

The machine is styled as a countertop gumball dispenser with a glass globe, enamel-red base, coin slot, turn knob, centered chute, one-time ball draws, and an optional mellow jazz-style ambient pad with rotating seventh chords. Audio starts after the first roll or when the sound control is enabled, respecting browser autoplay policies.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy with Vercel

1. Push this project to a GitHub repository.
2. Import the repository in Vercel.
3. Set Vercel's **Root Directory** to `bingo-pop`.
4. Use `npm run build` as the build command and `dist` as the output directory.
5. Click Deploy.

No environment variables are required.
